# 經銷商核心公關品申請系統

## 網站結構

- **首頁**（`/`）：經銷商核心使用，選項目/姓名 → 填企劃書 → 送出，或查詢自己的申請狀態。**沒有任何連結指向管理後台**，核心不會看到或誤點進去。
- **管理後台**（`/admin`）：只有你知道網址、登入後才能使用。
  - **審核申請**：核准／退回，可加備註。
  - **名單管理**：每季新增「項目 / 位階 / 申請人 / 補助金額」。

要進後台，直接在網址後面加 `/admin`（例如 `https://你的網址.vercel.app/admin`），建議你自己收藏這個網址。

## 表單欄位

**選擇申請資格**：項目、申請人（選了會自動帶出位階、補助金額，唯讀）
**企劃書內容**：活動主題、活動期間（開始/結束日期選擇器）、活動內容
**公關品統整**：商品／規格／數量／金額，每項自動算小計，列表底部顯示總計，可新增多筆品項
**收件資訊**：收件人姓名、電話、地址

## 部署步驟

### 第一步：建立 Supabase 專案

1. 到 [supabase.com](https://supabase.com) 建立一個新專案（或用現有的）
2. 左側選單 **SQL Editor** → 打開 `supabase_schema.sql`，整段複製貼上 → **Run**
   - 建立 `roster`（名單）和 `applications`（申請）兩張表

### 第二步：建立你的管理者帳號

**Authentication** → **Users** → **Add user**，設定登入 `/admin` 用的 Email／密碼

### 第三步：取得金鑰

**Settings** → **API**，複製 **Project URL** 和 **anon public** 金鑰

### 第四步：部署到 Vercel

1. 把整個資料夾上傳到 GitHub repo，或直接拖進 Vercel
2. [vercel.com](https://vercel.com) → New Project → 選這個 repo
3. **Environment Variables** 設定：
   - `VITE_SUPABASE_URL`
   - `VITE_SUPABASE_ANON_KEY`
4. Deploy

### 第五步：開始使用

1. 打開網址 + `/admin` → 用第二步的帳密登入
2. 「名單管理」新增這一季的項目/位階/申請人/補助金額
3. 把首頁網址（不含 `/admin`）分享給核心
